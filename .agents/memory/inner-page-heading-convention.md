---
name: Inner-page heading convention
description: Defines which Speedbird routes use the shared SectionHeading and semantic page sections.
---

Main club content routes should open with the shared `SectionHeading` and organize subsequent major content blocks as semantic sections. Home, Membership Application, and Members are intentional exceptions with purpose-specific layouts.

**Why:** The user explicitly wants consistent visual hierarchy and section structure across informational club pages while preserving the distinct landing, form, and members-area experiences.

**How to apply:** Use this convention for new informational routes and page-shell refactors. Do not automatically apply it to focused forms, account/member experiences, or the Home landing page.
